这一页会加载真正的面板本体，并直连真实接口（经本地反向代理走同源）。
凭据只存在你浏览器的 localStorage，不会发往任何第三方。

凭据怎么拿？
  1. 用同一浏览器打开官方页面并登录：
    https://zhxg.csu.edu.cn/znzhxgpt_h5/（PC 需先 F12 → Ctrl+Shift+M 开设备模拟）
  2. 在该页 F12 → Console 执行：
    copy(JSON.stringify({t:localStorage.getItem('token'),c:localStorage.getItem('casual')||localStorage.getItem('caasual')}))
  3. 把复制到的内容按字段粘到上面两个框里

更省事的做法：直接把这一行贴到官方页面 Console，面板立刻出现，不用来回复制凭据 ——
